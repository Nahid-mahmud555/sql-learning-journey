## How to Use & Practice

1. **Fork this Repository**
   Click the **Fork** button at the top-right corner of this repository to create your own copy.

2. **Clone Your Fork**

   ```bash
      git clone https://github.com/Nahid-mahmud555/sql-learning-journey.git
   ```

3. **Practice Daily**

   * Open the daily lesson folder.
   * Solve the exercises on your own.
   * Compare your solutions with the provided answers.
   * Commit your progress regularly.

4. **Track Your Learning**

   * Update the progress tracker after each lesson.
   * Add notes, challenges, and key takeaways.
   * Build a public record of your SQL growth.
